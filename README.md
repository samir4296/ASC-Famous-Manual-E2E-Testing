# ASC Famous – Manual E2E Testing

A manual end-to-end testing project for **ASC Famous**, covering multiple user portals, complex MLM business logic, commission calculations, user workflows, and administrative functionalities.

## 📌 Project Overview

This project focuses on manually testing the ASC Famous platform from an end-to-end perspective. Testing was performed across different portals and modules to verify functional requirements, user workflows, UI behavior, responsive layouts, and complex MLM business rules.

## 🧪 Testing Scope

* Functional Testing
* End-to-End (E2E) Testing
* Regression Testing
* UI/UX Testing
* Responsive Testing
* Business Logic Testing
* Cross-Portal Workflow Testing
* Validation & Negative Testing

## 🔍 Major Areas Tested

### MLM & Business Logic

* Sponsor/Upline Tree
* Binary Tree Structure
* User Placement Logic
* PV/BV Calculations
* Generation Commission
* Matching Commission
* Commission Distribution Rules
* Weak-Side / Strong-Side Logic
* User Activation & Eligibility Rules

### Admin & Functional Modules
